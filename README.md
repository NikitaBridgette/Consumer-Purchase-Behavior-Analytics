# Consumer Purchase Behavior Analytics

## Project Overview

Consumer Purchase Behavior Analytics is an end-to-end data analytics project focused on analyzing customer shopping patterns and purchasing behavior using Python, SQL, and Power BI.

The project aims to uncover actionable business insights related to customer demographics, spending habits, subscription behavior, product preferences, and sales trends. The workflow includes data cleaning, exploratory data analysis (EDA), SQL-based business analysis, dashboard creation, and presentation reporting.

---

## Dataset Information

* **Dataset Name:** Customer Shopping Behavior Dataset
* **Records:** 3,900 Rows
* **Features:** 18 Columns
* **Domain:** Retail / E-Commerce

### Key Features

* Customer demographics
* Product categories
* Purchase amount
* Subscription status
* Review ratings
* Shipping type
* Seasonal purchases
* Discount usage
